## Contexto

El TP4 exige que el tablero esté armado y gestionado en GitHub Projects con una columna/sección `TP4`. Sin esto el grupo no puede trackear el avance ni demostrar el proceso.

## Descripción

Crear el Project vinculado al repositorio, con las columnas, custom fields, labels y milestones definidos en la guía. Cargar las issues del TP4, asignar responsables y fechas, y dejar una vista filtrada por persona y otra por fase.

## Criterios de aceptación

- [ ] Project creado y vinculado al repositorio del TP.
- [ ] Columnas `Backlog`, `En curso`, `En revisión`, `Bloqueado`, `Hecho` configuradas.
- [ ] Custom fields `Responsable`, `Actividad`, `Fase`, `Prioridad`, `Fecha objetivo` creados.
- [ ] Labels y milestones creados.
- [ ] Las 23 issues del TP4 cargadas con responsable, fase y fecha.
- [ ] Vista "Por persona" y vista "Por fase" guardadas.
- [ ] Issue de prueba movida por todas las columnas para validar el flujo.
